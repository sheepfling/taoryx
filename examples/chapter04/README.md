# Chapter 4 TAOS examples

These files are maintainable transcriptions of the complete examples in Section 4.5
of the 1995 manual. Obvious scan/OCR artifacts and clear typesetting slips were
normalized so the examples can serve as parser and documentation fixtures.

They have not been executed against the historical TAOS 96.0 program, so their
presence in this repository should not be interpreted as runtime validation.
