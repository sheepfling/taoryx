# TAOS 1995 example corpus

This folder contains small fixtures that will exercise the grammar and file
format readers. They are deliberately minimal and marked as provisional until
the corresponding manual sections have been transcribed and checked.

- `grammar/example.taos` — a placeholder grammar sketch
- `tables/gravity.tbl` — an example table fixture
- `problems/free_fall.prb` — a problem fixture referring to the table and an
  equation registry entry
