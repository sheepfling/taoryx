# Repository instructions for Codex agents

## Purpose

This repository is the canonical semantic reconstruction of the 1995 TAOS User's Manual and the foundation for a typed `.tbl` / `.prb` language toolchain. The original source PDF is authoritative for historical wording and appearance. The LaTeX, metadata, fixtures, parser, QA reports, and generated products must remain mutually traceable.

## Environment setup

For a fresh checkout, install the complete contributor profile before doing
model or registry work:

```bash
python -m tools.dev bootstrap
source .venv/bin/activate
python -m tools.dev install-check
```

Bootstrap installs the core and all four official plug-in distributions in
editable mode. Do not infer that packages are installed merely because tests
can import sibling source roots. The install check requires actual distribution
metadata and entry points. Package profiles, individual installs, optional
extras, Windows activation, and troubleshooting are documented in
[docs/INSTALLATION.md](docs/INSTALLATION.md).

## Required commands

Run these before completing a change:

```bash
python tools/dev.py manual
python tools/dev.py equation-audit
python tools/dev.py check
python -m pytest
```

For a release bundle:

```bash
python tools/dev.py handoff
```

## Canonical and generated files

- `TAOS_manual_1995.pdf` is the original 307-page source.
- `manual/manual.tex`, `manual/chapters/`, `manual/frontmatter/`, `manual/backmatter/`, `manual/styles/`, `manual/figures/`, and `manual/math/` are the canonical LaTeX sources.
- `metadata/equations_provenance.csv` and `.json` are generated by `tools/audit_equation_provenance.py`; do not hand-edit them.
- `manual/backmatter/*_generated.tex` is generated from YAML metadata; edit the YAML and run the generator.
- `build/manual.pdf` is generated and normalized by `python tools/dev.py manual`.
- `qa/` contains generated audits, renders, and provenance assets. Retain source provenance when replacing any generated artifact.
- `examples/` contains documentation fixtures. Established `.tbl` and `.prb` fixtures must not be silently changed.

## Equation workflow

Every numbered equation must have exactly one:

- canonical number in `metadata/equations.csv`;
- LaTeX `eq:` label;
- source manual page and physical PDF page;
- TeX file and line range;
- exact display SHA-256 in the generated provenance registry.

After modifying any equation or equation label, run `python tools/dev.py equation-audit`. Do not claim executable implementation coverage merely because an equation is transcribed or section-level numerical checks pass.

## Python conventions

- Target Python 3.12 or newer.
- Use modern type annotations, such as `list[str | None]`.
- Prefer Pydantic, NumPy, SciPy, SQLAlchemy, and pytest when appropriate.
- End Python scopes with `####` in the established repository style.
- Preserve existing `TODO` markers.
- Add useful docstrings and comments, but avoid fragile inventories of every function.
- Tests belong under `tests/` and should use pytest.

## LaTeX and PDF conventions

- Keep equations, figures, tables, and examples semantic and editable.
- Preserve chapter-relative historical numbering.
- Record substantive source corrections in editorial metadata.
- Do not replace semantic figures with raster screenshots.
- After PDF-affecting changes, render and inspect the changed pages. Confirm no clipping, overlaps, broken glyphs, unresolved references, or overfull boxes.

## Parser boundary

`src/taoryx/language` is a canonical parser foundation, not yet a complete TAOS runtime. Complex block bodies, full default resolution, unit dimensions, lossless formatting, and complete control/search/optimization semantics remain future work. Do not claim runtime compatibility with TAOS 96.0 without the historical executable and table library.

## Agent workflow orientation

For practical recipes covering grammar validation, segment compilation,
scenario composition, batch and interactive stepping, plotting, and controls
