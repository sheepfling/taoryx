# Qualification policy

## Q0 — Source integrity

Exact bytes, source location/revision, SHA-256, document inventory, and redistribution notice are recorded.

## Q1 — Interchange validity

The source parses; references resolve; table dimensions and ordering are valid; unsupported features are explicit.

## Q2 — Static numerical validity

Embedded check cases and generated knot/interior/boundary cases pass in source units.

## Q3 — Canonical model validity

SI, FRD, reference geometry, CG/MRC transfer, and dimensional forces/moments agree with the source contract.

## Q4 — Host-dynamics validity

The model is bound to the correct environment, controls, states, event logic, and equations of motion.

## Q5 — Scenario qualification

Complete state and diagnostic histories are compared with the NASA/NESC participating-simulation family using declared interpolation, angle-wrap, absolute, and relative metrics.

Only Q5 models are scenario-qualified. Existing F-16, rocket, and HL-20 packages retain their current narrower qualification labels until the assigned NESC scenario suites are completed.
